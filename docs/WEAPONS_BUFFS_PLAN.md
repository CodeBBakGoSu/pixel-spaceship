## 1. 현재 게임 상태 진단 (`renderer-proto` `0bc1f99`)

v1 시점(3분 스크립트, 레벨 1~3, 드래프트 5종)의 진단은 더 이상 맞지 않아 교체합니다.

- **런:** 10:00, Coast/Skirmish/Siege/Storm/Ace 5페이즈, 페이즈 끝 15초 휴지기, Red Kite Ace 8:00(HP 1,200, 3단계). 고도 Stage C(49–230 m, 밴드 75/125/180, SKIM 14 m).
- **구현 완료:** 무기 W01–W10(Lv7), 버프 B01–B10(Lv3), 진화 10종, 계열 세트 보너스, Echo Overdrive, 상자 4개(C1/C3 보급, C2/C4 진화), Bills 5회, 3+3 → 4+4 슬롯, 과충전·고위험·리롤·추방·스킵, 격납고 8종, Heat 0–5, 체크포인트·철수, 일일 시드(KST), 카드의 전/후 수치와 픽 후 피드백. 시작 기체는 Hawk 1종.
- **적/스폰:** 정규 11종 + Gnat + Armored/Sting 변종 + Elite Carrier + Ace. 예약 예산과 minimum-live floor top-up, Gnat cap PC 200/폰 120, persistent wave/floor Gnats 및 앞쪽 재활용, encircle 편대가 구현됨. PC floor는 22/44/84/130/166, 모바일은 cap 비례 축소. 작업 브랜치에서 두 변종 동시 등장 검증 보고와 [녹화](https://app.devin.ai/sessions/9286f5ebd5a84c4fbdc8c96c6e8abdf9?testRecording=746df89d-adb1-4f8a-9b2d-aaba9638c4b0)가 있으나 통합 기준 검증 자료는 아닙니다.
- **무기 성장:** 10종의 모든 Lv2–7 rank change 코드와 Lv7 진화 조건이 구현됨. 전체 Lv2–7 스크린샷 수용 기준은 미검증입니다. 피해 숫자/크리 강조, Gnat 폭발 묶음, 5초 격추 카운터도 병합됨.
- **변종 통합 전 기준 시뮬:** `9d677b5`(변종 통합 전 후보), Heat 0, 데스크톱 seed 1–100/profile. skilled / 보통(average) / weak 순: clear 100%/75%/26%, Ace kill 99%/72%/2%, median kills 3,677.5/3,591/3,373.5, median peak Gnats 각 200. 보통(average) 프로필의 격추 중앙값 3,591은 기존 3,500 상한보다 91 높습니다. 이 표는 변종 통합 전 결과이며 `0bc1f99` 결과가 아니고, 렌더 FPS/현재 level-up 중앙값을 측정하지 않습니다.
- **성능 증거:** 기존 RTX 4090 결과와 모바일 에뮬 결과는 80/50 Gnat cap 시절 자료입니다. 피해 숫자 fixture의 VM SwiftShader는 High→Low auto-fallback 상태에서 36.44 fps를 측정했습니다. 현재 200/120 cap의 실제 PC/실제 폰 FPS는 미검증입니다.

## 2. 레퍼런스 리서치 — 훔칠 것 / 피할 것

### 2.1 Vampire Survivors
**사실(확인):**
- 무기 6칸 + 패시브 6칸. 레벨업마다 3~4개 선택지, 이미 가진 것을 고르면 업그레이드. ([Level up](https://vampire.survivors.wiki/w/Level_up), [Weapons](https://vampire.survivors.wiki/w/Weapons), [Passive items](https://vampire.survivors.wiki/w/Passive_items))
- 진화: 무기 최대 레벨 + 짝 패시브 보유 → 보스가 떨어뜨리는 **보물상자**를 열면 진화. 유니온(무기+무기)은 두 무기가 사라지고 슬롯이 하나 빈다. 대부분 맵에서 진화 상자는 10분 이후 보스. ([Evolution](https://vampire.survivors.wiki/w/Evolution), [AppGamer](https://www.appgamer.com/vampire-survivors-weapon-evolution-and-union-guide))
- 상자는 1/3/5개 보상 → 변동 보상. 상자 열 때 BGM을 끊고 전용 징글, 일시정지 연출이 스트레스 휴식 역할도 함. ([Game Design Lab 오디오](https://teemo.dev/game-design/vampire-survivors/systems/audio-design-and-feedback/), [Xbox Hub](https://www.thexboxhub.com/the-treasure-chest-trick-behind-vampire-survivors/), [Critical Play](https://mechanicsofmagic.com/2024/05/22/critical-play-vampire-survivors/))
- 메타: 골드로 영구 **PowerUp**(Might +5%/랭크 등 작은 퍼센트, 리롤/스킵/밴 횟수도 구매), 캐릭터 구매, 업적으로 무기/스테이지 해금, 리롤·스킵·밴. ([PowerUps](https://vampire.survivors.wiki/w/PowerUps), [Wikipedia](https://en.m.wikipedia.org/wiki/Vampire_Survivors))
- 아르카나: 런의 규칙을 바꾸는 카드(예: 모든 무기 투사체 +1 등). 해금 조건이 캐릭터 레벨 99 등. ([sulca.fr](https://sulca.fr/vampire-survivors) — 팬 사이트, 구버전일 수 있음 `[확인 필요]`)

**훔칠 것:** 짝 진화 + 상자 / 변동 보상 연출 / 작은 영구 PowerUp / 리롤·스킵·밴 / 규칙 바꾸는 카드(아르카나)
**피할 것:** 30분 런, 6+6 슬롯(우리는 약 9분), 해금 조건이 너무 막연한 것(막연한 업적은 "왜 안 풀리지" 좌절)

### 2.2 Brotato
- 대부분 캐릭터가 무기 6칸. 같은 무기 2개를 합치면 한 등급 위(4티어). ([Weapons](https://brotato.wiki.spellsandguns.com/Weapons))
- **무기 클래스 세트 보너스:** 같은 클래스 무기를 2~6개 들면 단계별 스탯 보너스(예: Precise = 크리 확률, Medical = 재생). ([Weapons](https://brotato.wiki.spellsandguns.com/Weapons))
- 웨이브 사이 **상점**: 4칸, 무료 락(잠금), 리롤은 웨이브가 지날수록 비싸지고 회차마다 가격 증가, 가격 인플레이션. ([Shop](https://brotato.wiki.spellsandguns.com/Shop), [Game Design Lab](https://teemo.dev/game-design/brotato/systems/shop-economy-and-run-structure-reference/))
- 캐릭터가 규칙을 바꿈(무기 종류 제한, 상점 가격, Gangster는 훔치기 vs 락 불가), 위험도(Danger) 단계가 적 체력/피해를 올림. ([Gangster](https://brotato.wiki.spellsandguns.com/Gangster), [Game Design Lab](https://teemo.dev/game-design/brotato/systems/shop-odds-prices-and-harvesting/))
- 하베스팅: 매 웨이브 이자처럼 복리로 늘어나는 유일한 소득원. 위 Game Design Lab 문서.

**훔칠 것:** 계열(클래스) 세트 보너스 / "캐릭터 = 규칙 변형" → 시작 기체 / 락·리롤 / Danger 단계 → Heat
**피할 것:** 상점 읽는 시간(우리 런은 약 9분이라 레벨업 모달만으로도 이미 바쁨), 스탯이 너무 많은 구조, 가격 공식 복잡도

### 2.3 Bills Must Be Paid (Rike Games, 2026-07-29 Steam 출시)
- 돼지 저금통을 망치로 깨 코인을 벌어 **청구서**를 갚는 짧은 액티브 인크리멘탈. 손 피로(스태미나)가 다 되면 런 종료. ([Steam](https://store.steampowered.com/app/4421010/Bills_Must_Be_Paid/), [공식](https://rikegames.com/bills-must-be-paid))
- 청구서는 기한이 있고, **갚으면 퍽 하나 선택**, 무시하면 **수금원이 수입의 일부를 떼감**. 파산 선언 후에는 반지/팔찌(영구 업그레이드)만 남고 나머지는 리셋. 스킬트리는 grip/caffeine/gym/wrist/luck + "rock rain", "electrified hammer" 같은 능력. 망치마다 데미지/속도/크리/반경이 다름. ([공식](https://rikegames.com/bills-must-be-paid), [Press kit](https://rikegames.com/press/bills-must-be-paid/))
- 리뷰 한 건(약 6시간에 클리어, 랜덤성이 적어 **엔딩 후 다시 할 이유가 적음**). ([Gaming with Marko](https://gaming.contentbymarko.com/bills-must-be-paid/)) — 한 리뷰어 의견이라 `[확인 필요]`지만, 우리에게는 중요한 경고입니다.

**훔칠 것:** "기한 있는 청구서 → 갚으면 보상 / 무시하면 페널티"(런 중 압박 + 목표), 기체(망치)별 개성
**피할 것:** 고정 스킬트리 + 랜덤성 부족 → 한 번 풀면 끝(이게 기현님이 걱정하는 "계속할 이유" 문제의 실제 사례)

### 2.4 Nova Drift (우주선 기반, 가장 가까운 레퍼런스)
- 기어 3종(무기/바디/실드)을 레벨업 때 교체, **모드**는 제한 없이 중첩, 모드는 4단계 트리이고 앞 단계를 사면 다음 단계가 선택 풀에 추가. 일부 모드는 붉은색 "대가" 효과. ([Basics](https://nova-drift.fandom.com/wiki/Basics))
- 슈퍼 모드: 특정 기본 모드 조합 + 랭크 조건 필요 → 사실상 "조합 진화". 랭크는 웨이브/보스로 쌓이며 최대 64. ([Rank Unlocks](https://nova-drift.fandom.com/wiki/Rank_Unlocks), [Steam 토론](https://steamcommunity.com/app/858210/discussions/0/3766733359276457157/) — 랭크 60 vs 80은 커뮤니티 기억이라 `[확인 필요]`)
- 도전 모드(Challenge Modes): 어려워지는 대신 점수/경험치 보너스. ([Lords of Gaming 리뷰](https://lordsofgaming.net/2025/05/nova-drift-review-a-unique-retro-rogue-lite/))

**훔칠 것:** 선택지 일부에 "대가가 있는 강한 카드"(고위험 카드), 도전 모드 → Heat, 조합 조건의 슈퍼 모드
**피할 것:** 트리 + 장기 런(웨이브 100+)이 전제인 구조, 우리 9분 런에는 과함(Nova Drift는 한 판 15~25분, 약 40번 업그레이드 — [개발 일지](https://blog.novadrift.io/path-of-exile-influence/))

## 3. 구조 결정: 조합 vs 스킬트리 vs 패시브

| 안 | 장점 | 단점(우리 게임 기준) | 판정 |
|---|---|---|---|
| **A. 자유 무기 조합**(무기+무기 → 합체) | "내 조합 발견" 느낌 | 조합 수가 N², 아트/밸런스 폭증, 3~4슬롯에서 슬롯 2개를 먹음, 시작 기체를 무기별로 따로 만들 부담 | 1차 MVP에서 **제외**, 나중에 Link 3~4개만(Phase 5) |
| **B. 짝 진화**(무기 + 짝 버프 → 진화) | 레시피가 1:1이라 콘텐츠 관리 쉬움, 예측 가능 + 발견의 재미, 상자 연출과 궁합 최고 | 레시피를 알려주는 UI 필요(도감) | **채택(코어)** |
| **C. 스킬트리** | 장기 목표가 눈에 보임 | 9분 런(레벨업 26~28번)에서는 노드를 고를 수는 있지만 랜덤 카드 풀이 한 판의 변주가 더 큼. 영구 트리는 시드 결정론/공정한 데일리 시드와 충돌(파워 차이). 모바일 UI 무거움. Bills 사례처럼 한 번 풀면 끝나기 쉬움 | **트리 UI는 안 함.** 대신 평평한 목록 업그레이드(VS PowerUp 식) |
| **D. 패시브 메타 강화**(평평한 영구 스탯) | 구현 쉬움, 진행감 | 많으면 파워 인플레 → 고도 밴드 조작 실력이 덜 중요해짐 | **작게만 채택**(합계 +10~15% 상한) |
| **E. 해금으로 풀 확장** | 파워 인플레 없이 새 장난감 → 리플레이 이유 | 퀘스트 설계 필요 | **채택(메타 코어)** |
| **F. 계열 교리**(같은 계열 2~3개 → 보너스) | 아트 추가 없이 "조합 느낌", 3~4슬롯에 잘 맞음 | 밸런스 | **가볍게 채택** |

**왜 트리를 안 쓰나(요약):** (1) v0의 "3분이라 노드가 적다"는 근거는 9분에서 **약해졌습니다**(솔직히 인정). 그래도 26~28번의 선택은 랜덤 카드 + 진화가 트리보다 한 판의 변주가 크고, (2) 3개 밴드 + 3개 뷰로 이미 학습량이 큼, (3) 결정론/시드 데일리의 공정성을 지키려면 영구 파워가 작아야 함, (4) Nova Drift의 모드 트리는 한 판 15~25분/약 40번 업그레이드의 더 긴 구조, Bills의 트리는 인크리멘탈 구조라서 성립하는 것. 트리가 필요해질 수 있는 지점은 Phase 3 이후 데이터를 보고 재검토.

**권장 하이브리드의 한 줄:** *"런 안: 4+4칸(시작 3+3) + 짝 진화 + 계열 교리. 런 밖: 해금 풀 + 작은 격납고 업그레이드 + Heat + 매일 시드."*

### 시작 기체와의 관계
무기 "조합"을 하려면 시작 무기가 다른 기체가 필요하다는 기현님 생각은 맞습니다. 다만 **A안을 안 쓰더라도 시작 기체는 가치가 있습니다**(리플레이 이유). 기체 = 시작 무기 1개 + 특성 1개(§9). MVP에서는 기본 기체 1대로 시작, Phase 4에서 3~4대로 확장을 권장합니다.

### 4.1 전제
- 목표 **9분**. 보스(Warden) **8:00 도착**, 보스전 60~90초 → 클리어 평균 약 9:15. **10:00 하드 리밋**(연료 한계 = 타임아웃, 기존 `timeout` 결과 재사용).

- 시드 결정론, 60Hz 고정 스텝 유지. 스폰은 시드 서브스트림으로 결정(§4.7).

- **휴식(lull):** 각 페이즈 마지막 15초(1:45, 3:45, 5:45, 7:45)는 스폰이 거의 멈추고 오브 회수 + 체스트 수령 + 선체 +2 회복(§4.13). 페이즈 전환 시 배너("PHASE 2 · SKIRMISH"). 7:45의 휴식은 **"WARDEN INBOUND" 경고** 포함.

### 4.4 레벨업 수와 XP 곡선 (약 26~28회 → v2 목표 42~48회)

> **v2 목표 (2026-11-23):** 첫 레벨업 **10초 이내**, 첫 1분 **3~4회**, 10분 **42~48회**, 4+4·Lv7 빌드(39픽)가 **7:30~8:00**에 거의 완성. 밀도 증가(§4.7 v2)와 무기 레벨 v2(§5.2)가 들어간 뒤 밸런스 봇이 `xpBase`/`xpPerLevel`을 맞춥니다(먼저 맞추면 XP 수입이 바뀌어 다시 해야 함). 아래 v1 계산은 참고용.

- **필요 XP:** `cost(n) = 14 + round(2.4 × n)`, n = 현재 레벨(1부터). 예: L1→2 = 16, L10→11 = 38, L20→21 = 62, L27→28 = 79. 27번 합계 약 1,285.

### 4.8 슬롯 수 재평가 (9분 기준)

계산 기준: 가용 업그레이드 = 레벨업 26~28 + 체스트 보너스(C1~C4 합계 약 8) + 청구서 보상(일부) ≈ **35 안팎**. 낭비 없이 쓴다고 해도 현실적 효율을 85%로 보면 **약 30픽**.
"최대로 채우는 데 필요한 픽" = `무기슬롯×무기최대Lv − 1(시작 무기 신규 공짜) + 버프슬롯×버프최대Lv`.

| 구성 | 무기 Lv/버프 Lv | 최대 필요 픽 | 평가 |
|---|---|---|---|
| 3 + 3 | 5 / 3 | 14 + 9 = **23** | **약 6~7분에 포화**(이후 선택이 "낭비") → 보스 직전 무의미한 카드. 신규 입문자용으로는 적당 |
| 4 + 3 | 5 / 3 | 19 + 9 = **28** | 보스 시점에 거의 완성 — 좋음, 버프 선택이 약간 단조 |
| **4 + 4 (최종형)** | 5 / 3 | 19 + 12 = **31** | **보스 도착(8:00) 즈음에 빌드가 완성**되는 곡선. 선택폭도 가장 큼 |
| 4 + 4 | 6 / 4 | 23 + 16 = 39 | 영영 못 채움. 레벨 폭 증가로 UI/밸런스 부담만 증가 |
| 6 + 6 (VS식) | — | 매우 큼 | 9분에 레벨 1~2에서 멈춤 + 모바일 화면 혼잡 → 비추천 |

**추천 = "4+4가 최종형, 3+3으로 시작, 4번째 슬롯은 해금"**
- 신규 플레이어는 **3+3**: 첫 몇 판은 화면과 규칙이 단순. 포화되는 약 6~7분 이후는 **오버플로 카드**로 대체(§4.9).
- **4번째 무기 슬롯** 해금 퀘스트(쉬움): "Phase 3(4:00) 도달" · **4번째 버프 슬롯**: "보스 도착(8:00) 도달 또는 에이스 랭크 3". → 첫 며칠 안에 열리는 **큰 해금 순간**(Megabonk도 퀘스트 개수로 슬롯을 여는 구조, [Unlocks](https://megabonkguide.wiki/unlocks) `[확인 필요: 커뮤니티 목록]`).
- **데일리 시드는 항상 4+4**(공정성).
- 대안(단순 안): **처음부터 4+3 고정**(해금 게이팅 없음). 개발은 가장 단순하지만 입문 난이도와 "슬롯 해금" 도파민을 포기.
- 모바일 UI: 슬롯 8개를 한 줄(약 40px × 8 = 320px, 세로 폰 폭 360px 안에 들어감 `[추정]`) 또는 4+4 두 줄.
- 기현님 원안 "총 3개"는 v0에서 이미 "무기 3 + 버프 3"으로 확장했고, v1에서는 이를 **시작 구성**으로 두는 형태로 유지.

### 4.9 카드 규칙
- 3장 제시(모바일 세로 3장, 데스크톱 가로 3장). 아이콘 + 한 줄 설명 + 현재 레벨 → 다음 레벨 변화.
- 이미 가진 것은 업그레이드 카드, 새 것은 NEW. 슬롯이 가득 차면 새 카드는 안 나옴.
- **짝 힌트:** 진화 가능한 짝이 한쪽만 있으면 ⭐ 표시.
- **Overcharged(과충전) 카드:** 약 8%, 보라 테두리, 효과 2배(Luck으로 증가).
- **고위험 카드(Nova Drift식):** 약 15%, 붉은 대가가 붙은 강한 카드. 선택 안 해도 됨.
- **리롤:** 기본 1회, 격납고에서 최대 3회까지. 밴/스킵은 해금.
- **오버플로 카드(3+3 포화 이후 / 모든 아이템 MAX일 때, VS의 Limit Break·Floor Chicken과 비슷한 역할, [Level up](https://vampire.survivors.wiki/w/Level_up)):** ① 선체 +2 회복 ② 전 무기 데미지 +5%(런 한정, 최대 3회) ③ 크레딧 보너스. 완전히 막힌 선택(낭비)을 없앱니다.
- **드래프트 난수는 별도 서브스트림**(`seed ^ pickIndex`)으로 전투 RNG와 분리.
- 26회 모달 → **퀵픽**: 원탭/숫자키, "추천" 별 표시, 짧은 애니메이션(0.3s), 설정으로 자동 선택 옵션(§4.14).

## 5. 무기 10종

### 5.0 고도 설계 원칙 (이 게임만의 정체성)
기본 규칙은 **같은 밴드 ±8m 안에서만 명중**입니다. 무기를 늘리되, 모든 무기가 같은 방식으로 맞으면 밴드 메카닉이 무의미해집니다. 그래서 각 무기에 **고도 커버리지 정체성**을 하나씩 줍니다.

| 유형 | 의미 | 해당 무기 |
|---|---|---|
| 같은 밴드 정밀 | 밴드 안 맞추기가 중요 | Rail Lance, Wing Pods |
| 한 칸 아래/위 커버 | 밴드 사이에서도 맞음 | Twin Cannon(기존), Arc Lightning(사슬이 ±1밴드 점프) |
| 호밍(고도 보정) | 고도를 무기가 맞춰줌, 대신 낮은 데미지/느림 | Seeker Missiles |
| 수직 기둥/면 | 한 번에 여러 밴드를 걸침 | Flak Burst(기둥), Ion Wake(오르내릴 때 수직 커튼) |
| 아래쪽 낙하 | 아래 밴드/후방 | Bomb Bay, Phoenix Flares(중력) |
| 궤도/기울어진 링 | 주변 근접 | Orbit Drones |

### 5.1 목록 (EN / KO, 행동, 레벨 스케일, 상호작용)

아래 무기별 Lv1–5 스케일 설명은 v1 설계 기록입니다. 실제 Lv1–7 구현 랭크는 §5.2 표가 기준이며, v1 수치·레벨 문구는 현재 구현 상태를 뜻하지 않습니다.

**무기 레벨은 1~5(MAX = 5)**. 공통 패턴: **Lv2 = 데미지/연사 +, Lv3 = 개수/크기 +, Lv4 = 데미지 +15%(공통 강화), Lv5(MAX) = 특수 효과 해금**. (v0는 MAX=4였으나 9분 런에 맞춰 한 단계 늘림.) 아래는 각 무기의 구체값(시작값).

#### W01 Twin Cannon / 쌍발 기관포 (시작 기체 기본, 계열: 탄도)
- **행동:** 전방 콘 자동 사격. 같은 밴드 + 한 밴드 아래(기존). 기존 Space 기동의 **오버드라이브**(2초) 대상 → 쌍발은 오버드라이브 효과가 가장 큼.
- Lv1 현재값 → Lv2 연사 +20% → Lv3 병렬 탄 +1(기존 "paired volley") → Lv4 데미지 +15%(공통) → Lv5(MAX) 탄이 약한 관통 1.
- **진화(+ Overdrive Coil): Aurora Gatling / 오로라 개틀링.** 총열 4개, 부채꼴 사격, 한 밴드 위까지 커버(아래+위+같은 밴드), 오버드라이브 때 오로라 빛줄기.
- **뷰:** COCKPIT에서 정밀 조준 가장 쾌적. **기동:** 루프 보너스의 핵심.

#### W02 Wing Pods / 윙 포드 (탄도)
- **행동:** 측면/후방 단거리 자동 사격(기존). 같은 밴드.
- Lv2 연사 +20% → Lv3 사거리 +25% → Lv4 데미지 +15%(공통) → Lv5(MAX) 후방 탄 +1.
- **진화(+ Hull Plating): Aegis Halo / 이지스 헤일로.** 포드가 기체 둘레를 도는 보호 링이 되어, 링에 닿은 적 탄을 상쇄하고 같은 밴드 적에게 접촉 피해.
- **뷰:** TOP에서 주변 위협 관리. **기동:** J-turn 중 측후방 커버.

#### W03 Seeker Missiles / 추적 미사일 (병기)
- **행동:** 쿨다운마다 3발. **±1 밴드 안의 적**을 잡고 **미사일이 고도를 보정해 날아감**(고도 맞추기 부담 대신 데미지는 직사 무기의 약 70%).
- Lv2 +1발 → Lv3 쿨다운 -15% → Lv4 데미지 +15%(공통) → Lv5(MAX) 폭발 반경 +30%.
- **진화(+ Fire Control): Swarm Rack / 군집 로켓.** 12발 일제 발사, 연기 궤적이 화면을 덮음, 정예에게는 락온 우선.
- **뷰:** CHASE에서 곡선 궤적이 예쁨. **기동:** 루프 직후 "자동 락" 한 번 더 발사(Echo 오버드라이브).

#### W04 Rail Lance / 레일 랜스 (에너지)
- **행동:** 0.9초 차지 후 전방 직선 **무한 관통** 광선. 같은 밴드 ±3m(좁은 창, 대신 줄 위의 모든 적 명중). 쿨다운 2.4초.
- Lv2 데미지 +25% → Lv3 쿨다운 -20% → Lv4 데미지 +15%(공통) → Lv5(MAX) 광선 폭 +1.5m, 한 밴드 아래도 명중.
- **진화(+ Band Lens): Prism Lance / 프리즘 랜스.** 세 밴드 각각에 하나씩 3줄 광선을 동시에 발사 → **고도 전부를 커버하는 유일한 무기.**
- **뷰:** COCKPIT에서 조준선(선이 어느 밴드에 있는지)이 가장 잘 보임 → "정밀 조준을 위한 콕핏" 이유 제공. **보스:** 약점 파괴용.

#### W05 Flak Burst / 대공 파열포 (탄도)
- **행동:** 전방 약 90m에서 터지는 포탄, 폭발이 **수직 기둥**(±18m)이라 밴드 사이에서도 맞음. 광역, 느림.
- Lv2 반경 +15% → Lv3 연사 +20% → Lv4 데미지 +15%(공통) → Lv5(MAX) 파편 6조각이 같은 밴드로 퍼짐.
- **진화(+ Capacitor): Skybreaker / 스카이브레이커.** 포탄이 연쇄 폭발(터진 자리에서 작은 포 3개 추가), 기둥이 세 밴드 전체로 확장 `[밸런스 위험: 가장 강력 후보]`.
- **뷰:** TOP에서 폭발 반경이 가장 읽기 쉬움. **졸개 스웜 처리 담당.**

#### W06 Ion Wake / 이온 항적 (에너지)
- **행동:** 기체 뒤에 이온 흔적을 남김(4초 지속). **추적하는 적이 흔적을 통과하면 피해.** 위/아래로 오르내리며 비행하면 흔적이 **수직 커튼**이 되어 여러 밴드를 커버. 기존 Space 기동의 `ManeuverTrail`(추적자 유인) 개념을 확장.
- Lv2 지속 +1s → Lv3 흔적 폭 +30% → Lv4 데미지 +15%(공통) → Lv5(MAX) 흔적 위에 오브 자동 끌어당김.
- **진화(+ Vector Thrusters): Plasma Ribbon / 플라즈마 리본.** 흔적이 끊기지 않고 날카로운 벽, 지속 8초, 같은 밴드 안 모든 적에게 틱 피해.
- **뷰:** CHASE에서 항적 곡선이 가장 잘 보임. **기동:** 루프/J-turn이 흔적 모양을 만듦 → 기동이 곧 무기 사용.

#### W07 Orbit Drones / 궤도 드론 (에너지)
- **행동:** 드론 2기가 기체를 공전(공전면이 ±10m 기울어 밴드 경계도 걸침). 접촉 피해 + 같은 밴드의 적 탄 차단.
- Lv2 드론 +1 → Lv3 공전 반경 +25% → Lv4 데미지 +15%(공통) → Lv5(MAX) 드론이 짧게 사격.
- **진화(+ Magnet Core): Collector Swarm / 수확 군집.** 드론 4기, **오브를 끌어와 수집**하고 지나간 자리의 적을 사격.
- **뷰:** TOP에서 공전/수비 범위를 읽기 쉬움. **졸개 근접 방어 담당.**

#### W08 Phoenix Flares / 피닉스 플레어 (병기)
- **행동:** 기존 **C 후방 플레어를 자동화**(쿨다운마다 뒤로 1발 자동 투하, 수동 C는 그대로 가능). 중력으로 떨어지며 추적하는 적을 태움(기존 flare burn 로직 재사용).
- Lv2 자동 간격 -15% → Lv3 불꽃 지속 +1s → Lv4 데미지 +15%(공통) → Lv5(MAX) 맞은 적이 번져서 주변 적에게 연소 전파.
- **진화(+ Flare Bay): Phoenix Rising / 불사조 비상.** 플레어가 불사조로 변해 가까운 적을 추적하며 불태움.
- **뷰:** 후방 미러(방금 키운 것)와 CHASE의 의미가 커짐. **고도:** 플레어는 떨어지므로 **아래 밴드 후방** 커버.

#### W09 Bomb Bay / 폭탄창 (병기)
- **행동:** 기체 아래로 폭탄을 6초마다 자동 투하, 낙하 후 근접 폭발. **아래 밴드**의 적을 노림(쌍발이 약한 쪽을 보완).
- Lv2 폭발 반경 +15% → Lv3 쿨다운 -20% → Lv4 데미지 +15%(공통) → Lv5(MAX) 폭탄 2발 연속.
- **진화(+ Ordnance Rack): Carpet Annihilator / 융단 소탕.** 한 번에 5발이 일렬로 투하(직선 융단).
- **뷰:** CHASE에서 낙하/폭발 고도를 읽음. **X 폭탄(수동)과 별개**로 유지(수동은 위기 탈출용).

#### W10 Arc Lightning / 아크 번개 (에너지)
- **행동:** 가까운 적에게 번개를 쏘고, 사슬이 **±1 밴드의 적에게도 60% 데미지로 점프**(밴드 다리 역할).
- Lv2 점프 +1 → Lv3 데미지 +20% → Lv4 데미지 +15%(공통) → Lv5(MAX) 점프 +2 & 마지막 점프에서 폭발.
- **진화(+ Salvage Beacon): Storm Crown / 폭풍 왕관.** 전기가 떨어진 오브에 번개를 내려 그 주변 적을 쓸어버림(오브 수집 도파민과 연동).
- **뷰:** TOP에서 사슬 연결 확인. **졸개 군집 청소 담당.**

> 참고: **Space 기동에 충격파/도미노 연쇄를 넣지 않습니다**(기현님이 "기본 무기 대폭 강화"로 확정). 아크 번개는 일반 무기로서만 사슬을 씁니다.

### 5.3 P0 · 무기를 고르면 어느 쪽이 비는가?

**설계 목표:** 역할은 피해 배수가 아니라 *언제 어디를 때릴 수 있는가*로 나눈다. 같은 역할 안에서도 접근법이 달라야 한다. 기존 탄도/에너지/병기 교리, 짝 버프와 진화는 유지한다. 아래는 측정된 서열이 아니라 고랭크·진화 후에도 남겨야 할 거래 조건이다.

**밸런스 비교용 장면(신규 계측):** 동일 시드·고도·입력·시간의 15초 구간에서 Lv4 한 종씩, 버프·진화·수동 폭탄 없이 비교한다. ① 양옆에서 같은 고도로 접근하는 Sting: 20 m 안까지 들어온 수(적을수록 좋음), ② 기수 앞 직선 Gnat 열: 통과 전 전방 격추 수, ③ 락 준비된 취약 Ace 단독: 실제 깎인 HP/초. 각각 Pods/Twin/Seeker를 대표로 삼아 담당 장면에서 다른 두 대표보다 좋은지, 어느 하나가 세 장면을 모두 이기지는 않는지 본다. 이후 동일 픽 예산의 위 두 입문 빌드를 같은 입력으로 비교한다. 수치가 뒤집히면 먼저 사각·표적 선택·명중률을 보고, 차이가 확인된 무기의 랭크별 피해/재사용 시간만 튜닝한다. §3.1 #8의 Seeker 속도 변경을 선승인하지 않는다.

## 10. 메타 진행과 "계속할 이유"

### 10.1 6개 층 (위가 가장 중요)
1. **발견 층(런 안):** 진화 레시피 10개, 교리, 2진화 런, 청구서 → "이번엔 다른 조합"
2. **해금 층:** 퀘스트로 무기/버프/기체 해금(§10.3). 풀이 늘어남 = 새 장난감(Halls of Torment, Megabonk 방식)
3. **격납고 층(작은 영구 업그레이드):** 크레딧으로 구매, **총합 +10~15% 상한**(§10.4)
4. **위험-보상 층(Heat):** Heat 0~5(§10.5)
5. **일일/공유 층:** 매일 같은 시드 + 리플레이/결과 카드(§10.6)
6. **에이스 랭크(장기):** 누적 점수로 랭크 상승, 랭크마다 해금 신호/치장(Nova Drift 랭크 방식) `[규모 결정 필요]`

### 10.2 화폐
- **크레딧(소프트):** 런 점수 + 페이즈 보너스 + 청구서 완료 + 클리어 보너스. 격납고 업그레이드에 사용.
- 퀘스트 해금에는 **크레딧을 안 씁니다**(조건만 달성하면 즉시 해금). Megabonk는 조건 달성 후 Silver로 다시 구매하는 구조라고 하는데([Unlocks](https://megabonkguide.wiki/unlocks)), 우리는 이중 장벽을 빼고 단순화하는 쪽을 제안합니다(해금 순간이 곧 보상이어야 하므로).
- **철수(Retreat) 시 크레딧 50%**(§4.14), 클리어 보너스는 100%.
- 이중 화폐(희귀 코어 등)는 도입하지 않습니다(복잡도 대비 이득이 작음).

### 10.5 Heat (Nova Drift 도전 모드 / Brotato Danger / VS Curse)
- Heat 1~5: 한 번 클리어하면 다음 단계 해금. 각 단계는 크레딧/점수 보너스(+15%씩).
- 예시: H1 적 체력 +15% / H2 적 사격 속도 +15% / H3 오브 자석 -20% / H4 보스 약점 +1 / H5 정예 수송기가 호위기와 함께 등장.
- 보너스를 받는 대신 **선택**임(강제 없음).

### 10.6 일일 시드와 "백엔드 없는" 리더보드
게임이 **시드 결정론 + 입력 로그 리플레이**를 이미 갖췄으므로 이점이 큽니다(리플레이 6시드 테스트 존재).

| 단계 | 방식 | 백엔드 | 비고 |
|---|---|---|---|
| 1 | **일일 시드** = 날짜(KST) 해시. 데일리 뮤테이터(예: "오늘은 Lancer 고정", "오늘 Twin 금지") | 없음 | 로컬 최고 기록(localStorage) |
| 2 | **결과 카드**: 시드/점수/랭크/빌드 아이콘을 이미지+텍스트로 복사, 친구와 비교 | 없음 | 모바일 공유 시트 |
| 3 | **리플레이 코드**: 입력 로그를 deflate + base64url로 짧게 압축해 공유, 가져오면 브라우저에서 재생/검증 | 없음 | 결정론이라 위조 어려움 |
| 4 | 서버 리더보드: 리플레이를 Node로 **서버에서 재시뮬레이션해 검증** 후 순위 등록 | 필요(Cloudflare Workers + D1/KV, Supabase 등 무료 티어 후보) | 요금/한도는 `[확인 필요]`. 위조 방지가 필요할 때만 |

- 1~3단계까지는 **서버 없이** 가능. 4단계는 유저가 늘어난 뒤에 결정하는 것을 권장.
- 전제: 드래프트 선택(`StageInput.pick`)도 입력 로그에 포함되도록 일반화 필요.

### 10.8 P2 · 실패해도 다음 출격에서 바뀌는 것

**골드는 기존 크레딧이다.** 일반 Survivors 지급액은 `내림((런 크레딧 + 점수/500 + Ace 격추 보너스) × Heat 배율 × 격납고 크레딧 배율 × 철수 배율)`. Ace 보너스는 격추 클리어만 250, 철수 배율은 철수만 0.5(그 외 1). 패배·시간 만료에도 번 몫을 전액 적립하고 퀘스트는 기존 누적/최고 기록 규칙대로 합산한다. 무성과 런 기본금은 없고 일일 출격은 개인 잔액·해금에 영향을 주지 않는다.

**무엇이 남나:** 크레딧 잔액, 격납고 구매, 퀘스트 진행과 해금된 드래프트 후보는 파일럿에 남는다. 이번 판의 무기 랭크·진화·버프는 잃는다. 예컨대 누적 오브 100개로 Drones가 열리면 *다시 고를 수 있는 것*이지 다음 판 무료 장착이 아니다. 첫 소비 후보는 기존 리롤 1단계(300 크레딧, 이후 런의 리롤 +1)로 보여 주되 구매는 선택이다.

1. **결과:** 정산 차액과 전후 잔액부터 쓴다. Heat 0·배율 1에서 런 크레딧 40과 점수 10,000으로 격추당했다면 `+60 크레딧 | 240 → 300`. 바로 아래에 새 무기와 역할을, 없으면 가장 달성 비율이 높은 잠긴 무기 하나의 행동과 `이전 → 현재 / 목표`를 표시한다(동률은 퀘스트 표 순서, 전부 열었으면 숨김).
2. **다시 출격:** 구매 없이 한 번에 시작한다. 보조 동선은 기존 격납고와 연결한다. 구매 가능하면 비용과 효과, 부족하면 차액만 표시한다. 리롤 구매 후에는 실제 잔액·단계·다음 런 리롤 수가 즉시 바뀌어야 한다.
3. **새 무기 시험 출격(신규, 선택):** 결과에서 열린 무기 중 하나를 지정한다. Hawk/Twin으로 출발해 다음 일반 런 첫 드래프트의 **기존 무기 보장 자리**에 해당 무기를 한 번 제시한다. 슬롯·네 번째 카드를 추가하지 않는다. 거절·리롤 뒤엔 통상 규칙, 부적격이면 원래 드래프트다. 일반 재도전·일일·Legacy에는 개입하지 않는다. 최근 정산의 미사용 시험 후보 ID만 저장하고 시험 출격 시 하나를 런 시작 입력으로 넘긴 뒤 후보를 비운다. 체크포인트는 선택 ID와 제시 여부를 보존하고 옛 저장은 예약 없음으로 읽는다.

**검수 예:** 오브 80개를 모은 파일럿이 20개 더 모으고 패배 → Drones 해금 → 새로고침 후 잔액·해금 유지 → 시험 출격 첫 3장 중 Drones 1장 → 선택하면 일반 슬롯 소비. 결과 재표시·복구가 지급을 반복하면 실패다. 위 점수·예산으로 철수하면 +30, 시간 만료면 +60, 일일이면 +0이고 프로필 불변이어야 한다.

**상점과의 경계:** [워프 비컨 상점 초안](https://github.com/CodeBBakGoSu/pixel-spaceship/blob/e25e994/docs/SHOP_PLAN.md)은 협곡→궤도 사이 *런 안*에서 회수품으로 보급하며, ‘영구’ 항목도 같은 런의 다음 루프까지만 남고 게임 오버 때 초기화된다. 재사용할 것은 구매 전후값·잔액 부족 표기뿐이다. 그 가격표·회수품·상점 정지를 Survivors로 옮기거나 크레딧으로 환전하지 않는다. 새 기체·도감은 #9에 남긴다.

### 11.1 P1 · 강해진 소리, 잭팟, 화면을 채우는 궤적

**타격음은 음량보다 층수로 키운다.** 아군이 실제 피해를 준 이벤트를 80 ms 단위로 모은다. 한 번 맞으면 짧은 타격음, 같은 구간 3회 이상이면 저음 한 겹, 크리티컬 또는 Gnat 6기 이상 격추면 고음 한 겹을 더한다(창당 각 1회, 전투 중 보상음 동시 3개까지). 기존 격추 폭발음을 복제하지 않는다. 선체 피격과 적 명중의 음색을 구분하고, 경고가 울리면 보상음만 낮춘다. 기존 SFX 음소거·볼륨·리미터를 따른다. 수치는 청음 테스트용 시작값이다.

**상자 릴은 결과를 보여 줄 뿐 보상을 정하지 않는다.** §4.5의 수송기/수집 고도, C1·C3 가중치와 Luck, C2·C4 진화 조건을 유지한다. 기존 3칸 릴·추가 보상 목록·건너뛰기를 재사용하고, 이미 적용된 `chestReveal` 내용만 연출한다. 시간은 개봉부터 결과를 읽을 때까지의 **실시간 목표**이지 강제 대기 시간이 아니다.

| 실제 결과 | 보상 공개 순서 | 최대 시간 |
|---|---|---:|
| 보급 1개 | 잠금음 → 해당 아이콘과 레벨만 점등 | 0.4초 |
| 보급 3개 / 진화 미충족 3업 | 세 칸 순차 정지 → 3음 상승 → 실제 보상 표시(진화 표식 없음) | 0.9초 |
| 보급 5개 | 세 칸 정지 → 나머지 두 보상 펼침 → 금빛 테두리·화음과 ‘잭팟 ×5’ | 1.4초 |
| 실제 진화 | 선택한 무기→진화 아이콘 변신 → 전용 종지음 → 실제 보너스 1~2개 표시 | 1.4초 |

Bill 보상은 같은 화면을 쓰더라도 짧은 명세만 띄운다. 빈 칸을 당첨처럼 표시하지 않는다. 건너뛰기는 **동일 결과에 즉시 정지**, ‘계속’만 전투를 재개한다. 모션 줄이기는 회전·섬광·흔들림 없이 같은 이름/수량을 즉시 표시한다. 개봉 중에는 게임 시계가 멈추고, 음소거·건너뛰기·탭 연타로 보상이나 다음 난수가 달라지지 않는다.

**화면을 채우되 위험은 읽히게 한다.** Twin Lv1의 두 짧은 탄선과 Lv7의 여섯 갈래, 진화 Seeker의 12개 곡선 궤적이 구분되게 한다. 연기는 *실제 탄* 뒤에만 붙는 비충돌 잔상이다. 장식 궤적 풀은 PC 48/폰 24개로 시작하고 초과 시 오래된 잔상부터 생략한다. 적탄·락온·기체 윤곽·고도 경고를 그 위에 남긴다. Low/모션 줄이기는 잔상을 줄이되 원래 탄과 경고는 보존한다. 128발 시뮬 예산·피해량·스폰은 늘리지 않는다.

- **크기:** 24×24 원본, 데스크톱 3×(72px), 모바일 2×(48px). 최근접 확대. 콘셉트 시트는 4×.

- **팔레트(16색 내외):** 강철 3톤(#dfe8f7 / #9fb2d0 / #5a6c92), 시안(#3de0ff) = 에너지/고도, 오렌지(#ff9a2e) = 탄도/화염, 빨강(#ff4a5a) = 병기, 초록(#5be37d) = 정보/조준/수집, 노랑(#ffe14d) = 번개/하이라이트, 보라(#a77bff) = 과충전.
- **프레임(등급):** 일반 = 강철 회청색, 고급 = 초록, 희귀(과충전) = 보라, **진화 = 금색 + 점선 반짝임**. 모서리 노치로 유형 구분: **주황 = 무기, 시안 = 버프**(색약 대비를 위해 노치 모양도 다르게 할 수 있음, 시안은 마름모형 등 `[결정 필요]`).
- **실루엣 우선:** 24px에서 한눈에 구분되도록 무기마다 고유 윤곽(관통 광선 = 세로 선, 플랙 = 별 모양, 드론 = 링 + 점 등).
- **파일 규격:** 스프라이트 시트 한 장(atlas PNG) + JSON(이름, 좌표). 프레임은 코드에서 합성(등급 변경이 쉬움). 레벨 표시는 아이콘 아래 점 1~4개.
- **콘셉트 시트:** `icons-concept.png`에 위 규칙으로 20개를 절차 생성해 둠(코드 `make_icons.py`, 최종 아트 아님). 최종은 사람이 다듬거나 이 생성기를 기반으로 개선.
