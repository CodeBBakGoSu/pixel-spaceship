## 무기 10종

모두 최대 Lv7. 무기 Lv7과 짝 버프 Lv1 이상을 갖추면 **진화 상자**에서 해당 진화를 고를 수 있다. 버프를 얻는 즉시 진화하는 것은 아니다. [레벨별 무기 수치와 진화 조합](../../src/data/items.ts) · [진화 판정](../../src/progression.ts)

| 무기 | 발사 방식 | 획득 | 짝 버프 → 진화 |
|---|---|---|---|
| 쌍발 기관포 | 정면과 한 밴드 아래로 사격 | 시작 장착 | 과부하 코일 → 오로라 개틀링 |
| 윙 포드 | 같은 고도의 가까운 측면·후방을 독립 사격 | 기본 후보 | 장갑판 → 이지스 헤일로 |
| 추적 미사일 | 위아래 한 밴드까지 표적을 추적 | 기본 후보 | 사격통제 → 군집 로켓 |
| 레일 랜스 | 충전한 좁은 광선이 한 줄을 관통 | 퀘스트 | 대역 렌즈 → 프리즘 랜스 |
| 대공 파열포 | 전방에 세로로 긴 파편 폭발 | 퀘스트 | 축전기 → 스카이브레이커 |
| 이온 항적 | 비행 경로를 따라 피해 지대를 남김 | 퀘스트 | 벡터 스러스터 → 플라즈마 리본 |
| 궤도 드론 | 기체를 돌며 접촉하는 적을 공격 | 퀘스트 | 자석 코어 → 수확 군집 |
| 피닉스 플레어 | 기체 뒤와 아래로 불타는 플레어 투하 | 기본 후보 | 플레어 베이 → 불사조 비상 |
| 폭탄창 | 기체 아래로 폭탄 자동 투하 | 기본 후보 | 폭장 랙 → 융단 소탕 |
| 아크 번개 | 주변 표적과 이웃 밴드로 연쇄 | 퀘스트 | 인양 비콘 → 폭풍 왕관 |

## 버프 10종

모두 최대 Lv3. 예를 들어 이번 판에 얻은 **장갑판**은 격추되면 사라지지만, 크레딧으로 산 **격납고 선체 강화**는 다음 일반 출격에도 남는다.

| 버프 | 이번 판에 바뀌는 것 (Lv1 / Lv2 / Lv3 예) | 획득 |
|---|---|---|
| 과부하 코일 | 기동 오버드라이브가 0.5 / 1 / 1.5초 길어지고 에코가 강해짐 | 기본 후보 |
| 장갑판 | 최대 선체 +1 / +2 / +3, 단계 상승 때 수리 | 기본 후보 |
| 자석 코어 | 회수 반경 ×1.2 / ×1.4 / ×1.6, 수집 고도 범위 확대 | 기본 후보 |
| 대역 렌즈 | 명중 고도 허용 폭 +1 / +2 / +3 m | 퀘스트 |
| 벡터 스러스터 | 기동성 ×1.08 / ×1.16 / ×1.25 | 퀘스트 |
| 플레어 베이 | 플레어 재고 +1 / +2 / +3, 재장전 단축·연소 연장 | 퀘스트 |
| 폭장 랙 | 폭탄 재고 +1 / +2 / +3, 재장전 단축·폭발 반경 증가 | 퀘스트 |
| 사격통제 | 치명타 확률 5 / 10 / 15%, 조준 고정 시간 단축 | 퀘스트 |
| 축전기 | 무기 재사용 대기 시간 ×0.94 / ×0.88 / ×0.82 | 기본 후보 |
| 인양 비콘 | XP·크레딧 ×1.1 / ×1.2 / ×1.3, 보상 확률 보정 | 기본 후보 |

## 격납고 강화 8종

일반 출격에서 번 크레딧으로 단계별 구매한다. 표의 값은 **현재 개발판**의 영구 효과이며, 일일 출격에는 미적용이다. [가격·랭크 정의](../../src/data/meta.ts) · [구매·출격 능력치 계산](../../src/meta.ts)

| 강화 | 구매 후 효과 | 단계별 가격 (CR, 왼쪽부터 구매) | 필요 랭크 |
|---|---|---|---:|
| 선체 강화 | 시작 선체 10 → 11 → 12 → 13 | 450 / 1,100 / 2,450 | 1 |
| 다시 뽑기 | 시작 리롤 1 → 2 → 3회 | 300 / 1,100 | 1 |
| 카드 제거 | 0 → 1 → 2회 | 750 / 2,000 | 2 |
| 건너뛰기 | 0 → 1 → 2회 | 550 / 1,650 | 2 |
| 회수 자석 | 단계당 기본 오브 흡입 반경 +10% (2단계) | 400 / 1,350 | 1 |
| 경험치 보너스 | 단계당 기본 XP +3% (5단계) | 700 / 1,250 / 2,300 / 3,900 / 6,250 | 1 |
| 크레딧 보너스 | 단계당 출격 크레딧 +10% (5단계) | 400 / 950 / 1,850 / 3,550 / 6,500 | 1 |
| 비상 복구 | 출격당 한 번 선체 0에서 최대 선체 절반(올림)으로 복구 | 10,000 | 1 |

**아직 기획:** [Hawk 미리보기·아이콘·구매 전후 수치 비교](../WEAPONS_BUFFS_PLAN.md#hangar). 강화 자체와 새 격납고 화면은 같은 상태가 아니다. 다른 기체를 추가할지는 미정이다.

## 해금 퀘스트 10종

조건을 채운 장비는 일반 추첨 후보가 된다. 구매하거나 다음 런 첫 카드에 예약할 필요가 없다. ‘한 출격’/‘한 번’ 조건은 여러 판에 나눠 채울 수 없고, ‘누적’ 조건은 일반 출격의 정산을 이어서 채울 수 있다. [조건·집계 방식](../../src/data/meta.ts) · [게임 안 한국어 명칭](../../src/i18n.ts)

| 해금 대상 | 조건 | 집계 |
|---|---|---|
| 레일 랜스 | Ace를 5회 명중 | 한 출격 |
| 대공 파열포 | 5초 안에 서로 다른 3개 고도 밴드에서 격추 | 한 출격 |
| 이온 항적 | 기동 30회 | 누적 |
| 궤도 드론 | 회수 구슬 100개 수집 | 누적 |
| 아크 번개 | ACE WIPE ×6 달성 | 한 번 |
| 대역 렌즈 | 저·중·고 세 밴드에서 모두 격추 | 한 출격 |
| 벡터 스러스터 | 부스트 60초 사용 | 누적 |
| 사격통제 | 조준 고정 격추 20기 | 누적 |
| 플레어 베이 | 후방 플레어로 추격기 20기 격추 | 누적 |
| 폭장 랙 | 수동 폭탄 10회 투하 | 누적 |

수동 폭탄 조건은 이 개발판 기준이다. [자동 폭장 실험](https://github.com/CodeBBakGoSu/pixel-spaceship/pull/8)은 별도 PR이므로 병합 전에는 표에 섞지 않는다.
